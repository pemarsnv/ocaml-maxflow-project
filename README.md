# OCAML Maxflow Project 

This project is an implementation of the Ford-Fulkerson algorithm in OCaml. 

## How to use ? 

### Compilation 

`make` 

### Execution 

Once you compiled the executable, here is an example of an execution command : 

`./ftest.exe [base graph path] source sink [result destination]`

And to be able to display the graph graphically, you can use the following command : 

`dot -Tsvg [result graph path] [image destination]`
